# 河北采购数据看板 · 可吸收骨蜡（颐封）

京津冀3+N联盟止血材料类医用耗材带量联动采购（第一年度）河北省采购数据看板。

- 数据源：`协议签订与采购统计.xlsx`（河北省医疗器械集采平台导出）
- 核心字段：医院名称、是否签署协议、协议量（执行协议量）、订单数量、发货数量、发货金额、完成进度
- 交互：按地区 / 签署状态 / 医院名筛选，表头点击排序，图表随筛选联动
- 渲染：纯离线（SVG/CSS 自绘），无外部依赖

## 本地预览
直接用浏览器打开 `index.html` 即可。

## 数据口径
- 协议量取"执行协议量"
- 完成进度 = 发货数量 ÷ 执行协议量（部分医院因订单超量而 >100%）
- 全部数值读取自源表，未做修改
